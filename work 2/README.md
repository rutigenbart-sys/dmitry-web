# dmitry-web.ru — сайт «Создание сайтов с нуля»

Статический сайт (HTML/CSS/JS без фреймворков), генерируется Python-скриптом.
141 страница: главная RU/EN, 25 городов, 108 статей, блог, политика, условия, 404.

## Сборка
```
python3 build.py        # результат в папке dist/
```
Пересобирайте **раз в год** (в январе): в title, schema и статьях подставится новый год.
Видимый год на страницах обновляется сам через JS.

## Настройки — config.json
| Поле | Что сделать |
|---|---|
| `max` | сейчас заглушка `https://max.ru/` — вставьте свою ссылку на профиль в Max |
| `form_endpoint` | адрес приёма заявок (см. ниже). Пока пусто/неверно — форма откроет Telegram с готовым текстом |
| `metrika_id` | номер счётчика Яндекс.Метрики |
| `yandex_verification`, `google_verification` | коды подтверждения из Вебмастера и Search Console |
| `pay_url` | ссылка на оплату предоплаты 5 000 ₽ (появится кнопка после квиза) |
| `inn` | ваш ИНН (подставится в политику и условия) |
| цены | `price_landing`, `price_shop`, `price_card`, `prepay`, `domain_cost` |

После правок: `python3 build.py`.

## Заявки в Telegram
1. В Telegram откройте @BotFather → `/newbot` → получите **токен**.
2. Напишите своему боту `/start`; свой **chat id** узнайте у @userinfobot.
3. Вариант А — PHP-хостинг: заполните константы в `server/send.php`, загрузите его в корень сайта, `form_endpoint` = `/send.php`.
4. Вариант Б — GitHub Pages + Cloudflare Worker (бесплатно):
   `cd server && npx wrangler deploy`, затем `wrangler secret put BOT_TOKEN` и `wrangler secret put CHAT_ID`;
   в `config.json` укажите `form_endpoint` = адрес воркера. Пересоберите сайт.
Токен нельзя класть в `dist/` и в публичный репозиторий.
Защита от спама: скрытое поле-ловушка, проверка времени заполнения, лимит по IP (PHP).

## Публикация
- **GitHub Pages**: содержимое `dist/` в репозиторий (файл `CNAME` уже есть), в DNS домена — A-записи GitHub Pages и CNAME для `www`, включить HTTPS.
- **Обычный хостинг**: загрузить `dist/` в корень (для Apache есть `.htaccess` со сжатием и кэшем).

## После запуска
1. Яндекс Вебмастер и Google Search Console: добавить сайт, подтвердить, отправить `https://dmitry-web.ru/sitemap.xml`.
2. Установить Метрику, вписать `metrika_id`, настроить цели: `lead_form`, `quiz_lead`, `quiz_step_1..3`.
3. Отзывы: `reviews.json` — впишите реальные, поставьте `"published": true`. Пока блок скрыт.
4. Кейсы помечены «Концепт» — замените на реальные работы, когда появятся.

## Честно о содержимом
- Статьи (108) собраны по шаблонам по нишам — выборочно перечитайте и дополняйте своим опытом, так они лучше ранжируются.
- Тексты политики и условий — рабочие черновики, не юридическая консультация.
- Позиций в выдаче сайт не обещает.

## Структура
`build.py` + `b_*.py` — генератор; `data_cities.py`, `data_niches.py` — данные городов и ниш; `site/assets` — стили, JS, шрифты, изображения;
`src_img/` — оригиналы фото; `tools/optimize_images.py` — пересборка AVIF/WebP/JPG.
